# ResetLocation 側載安裝

Customized by Platyun

這份下載包不需要發布者架設伺服器。下載 IPA 後，由使用者在自己的電腦上，以自己的 Apple 帳號重新簽名並安裝。

## 選擇檔案

- `ResetLocation-0.1-AppOnly-unsigned.ipa`：建議先測試。只有主 App，沒有桌面小工具，也不提供小工具的共用冷卻與一鍵操作。
- `ResetLocation-0.1-WithWidget-unsigned.ipa`：包含桌面小工具。重新簽名需要正確處理 App、extension 與 App Groups；本版尚未完成側載真機驗證，不保證小工具可用。

兩份都是未簽名 IPA，不能直接在 iPhone「檔案」App 點開安裝。沒有附帶發布者的簽名憑證或描述檔。

## 使用 Sideloadly 安裝

作者僅有 Mac，未測試 Windows PC 的安裝流程；Windows 使用者請自行斟酌。Mac 上的 Sideloadly 側載流程也尚未完成實測。

1. 在自己的 Windows 或 Mac 從 [Sideloadly 官方網站](https://sideloadly.io/)下載工具。
2. 用 USB 連接 iPhone，解鎖並依提示信任電腦。
3. 開啟 Sideloadly，選擇自己的 iPhone，載入 `AppOnly` IPA。
4. 在本機工具登入自己的 Apple 帳號，依提示簽名與安裝。不要把帳號密碼交給發布者。
5. 依需要在 iPhone「設定 → 一般 → VPN 與裝置管理」信任開發者；若要求開發者模式，在「設定 → 隱私權與安全性」啟用並完成提示。
6. 開啟 ResetLocation，先確認介面檢查結果，再依操作手冊使用。若啟用開發者模式曾重開手機，要等原本問題再次出現，才能評估 App 的效果。

免費帳號簽名通常有效 7 天，需要定期刷新；可使用工具的自動刷新功能，仍需自己的電腦配合。詳見 [官方 FAQ](https://sideloadly.io/faq)。

## 小工具版本

先確認主 App 可安裝，再測試 `WithWidget`。簽名工具若移除 extension、App Groups，或改寫識別碼但未對應程式中的群組名稱，小工具可能無法顯示狀態或送出請求。不要將主 App 安裝成功當成小工具驗證通過。

若工具要求變更 Bundle ID，請記錄實際設定；不同識別碼或簽名可能形成另一份安裝，無法保證保留原先資料。不要為了測試先刪除原本可用的版本。

App 是實驗工具。回傳 YES 或「請求已返回」不代表定位服務已重啟或快取已清除，效果需回到原本的定位工具確認。
